# Streamr 0.1.4

### A cleaner app frame

- Removed the custom title panel across the top of the app.
- Moved the Streamr logo to the top of the sidebar and removed its search shortcut row.
- Removed the duplicate My Library button beside the top search field.
- Kept the search field and made the remaining top bar draggable for frameless desktop windows.

### A clearer viewing journal

- Added a responsive, GitHub-style activity calendar with searchable month selection and daily activity details.
- Added a monthly viewing-activity area chart with searchable 6- and 12-month ranges.
- Added library completion and movie, series, and anime mix charts with clearer totals and interactive details.
- Daily activity is saved locally, tracks each title/action once per day, and is included in JSON backups.
- Existing titles are represented using their last saved activity date; daily tracking continues from this update onward.
- Improved calendar and chart layouts for narrower app windows.

Your existing library and window preferences are kept when upgrading from v0.1.3.
