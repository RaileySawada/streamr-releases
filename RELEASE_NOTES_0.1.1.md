## Streamr v0.1.1

### Search fix

- Fixed Everything searches being rejected by the shared catalog service.
- Improved the search error heading when a request cannot be completed.
- The service fix also restores Everything search in installed v0.1.0 apps.

### A more focused watch page

- Episodes and season selection sit beside the player for titles with multiple episodes.
- Search the episode queue and choose auto-play next episode from the same panel.
- Below the player, title and metadata occupy the left column; watchlist, watched status, and server controls occupy the right column.
- The synopsis stays visible while additional title information is collapsed by default.
- Removed the duplicate synopsis and oversized playback settings panel.
- On narrow windows, the episode queue moves below the main viewing area.

### Updates and fullscreen

- Preview the pending version's release notes from the update notification before restarting.
- Updates download in the background with a dismissible bottom-right notification.
- Choose Restart & install when you are ready; playback continues until then.
- Release notes appear once per installed version.
- Fixed the player fullscreen control in Electron.
- Removed the redundant episode panel heading and placed the compact season selector beside episode search.

### Updating

Open Settings → App updates after this release is published, or download the x64 or ARM64 installer from Assets. Export a library backup before updating if you want an extra copy of your data.
