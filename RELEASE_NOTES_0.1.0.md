## Streamr v0.1.0

The first public release of Streamr for Windows.

### Discover your next watch

- Browse movies, TV series, and anime.
- Combine genre and year filters, with popularity, rating, and release-date sorting.
- Explore title details, full cast and crew, and additional TMDB information when available.
- Save a watchlist and continue watching when the player reports progress.
- Choose light, dark, or system appearance.
- Back up and restore your library and preferences with JSON export/import.
- Remember your window size, position, and display state.

### Automatic update checks

Installed Windows builds check for stable Streamr releases after opening and every six hours. Open **Settings → App updates** to check manually.

- Download an available update when you choose.
- See download progress.
- Restart and install when you are ready.
- Separate x64 and ARM64 metadata selects the matching installer.
- No GitHub account or source repository access is required.

### Install Streamr

Download the appropriate installer from Assets and follow the setup steps. This first release must be installed manually; it will check for future versions after installation.

- **x64**: Intel and AMD 64-bit Windows PCs.
- **ARM64**: Windows on ARM PCs.

Requires Windows 10 or Windows 11. Installers are unsigned. Internet access is required for catalog browsing, playback, and update checks. Playback availability and progress reporting depend on external providers.
